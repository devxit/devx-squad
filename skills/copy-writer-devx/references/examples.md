# Exemplos copy-writer-devx

## Sobre institucional

**Pedido:** Copy da página Sobre da ACME.

**Triagem:** modo página web → `arquetipo_id: institutional` → `site-par-v1` se SEO pedido.

**Saída (esqueleto):** blocos `hero`, `mission`, `proof`, `people-values`, `contact-cta` — sem dobras de oferta agressiva.

## Artigo de blog

**Pedido:** Outline e lead para “como integrar API X”.

**Triagem:** `blog-editorial`; irmã se indexação/citação em IA importar.

**Saída:** `lead` 40–60 palavras; `outline` H2; `conclusion` com próximo passo.

## LP campanha

**Pedido:** LP completa para demo B2B.

**Triagem:** `landing-campaign`; `site-par-v1`; 4 insumos na FASE 1.

**Saída:** blocos `hero` … `faq` (7 equivalentes).

## Disparo — deve / não deve

| Deve | Não deve |
| --- | --- |

| Microcopy modal de exclusão | Gerar JSON-LD completo sem irmã quando só copy pedida |
| Prompt UI lista de KPIs minimalista | TDD backend |
